# オルカンに勝てん！

kawauso 作『オルカンに勝てん！』を、縦スクロールで読むためのページです。全107ページを原作の順序で掲載しています。98〜105ページは原作の補足表記 A1〜A8 も併記しています。

- 下へスクロールして読み進めます。目次、ページ番号、前へ・次へからも移動できます。
- ページごとの「拡大」で細かい文字を読めます。＋・−で倍率を変え、スクロールやドラッグで移動できます。「幅に合わせる」で戻り、「閉じる」または Esc で本文へ戻ります。
- キーボードでは Tab で操作を選び、Enter で実行できます。本文では ←・→ でも前後のページへ移動できます。
- 読書位置は、このブラウザーに保存します。保存できない環境でも読めます。URL末尾の `#p=66` のような番号を使うと、そのページを直接開けます。
- 出典は各ページ下の「このページの出典・参照」から開けます。外部の出典は新しいタブで開きます。
