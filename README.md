# オルカンに勝てん！

kawauso 作『オルカンに勝てん！』全107ページのWebリーダーです。原作のページ順を維持し、98〜105ページは補足表記 A1〜A8 も併記しています。

- PCは見開きを基本に、1ページ・縦読みへ切り替えられます。表紙は単独、続いて右に2ページ・左に3ページを表示します。目次・ページ番号・前へ・次へでも移動できます。
- 高さ・幅に合わせる、倍率の＋・−とスライダー、全画面ボタンで読みやすい大きさを選べます。拡大時はスクロールやドラッグで移動できます。
- 見開き・1ページ表示では本文上のホイールを下へ回すと次、上へ回すと前へ進みます。拡大中や出典欄では通常のスクロールを使えます。
- キーボードは Tab と Enter で操作できます。PCのページ表示では ← が次、→ が前、PageDown・PageUp でも移動できます。拡大中の矢印キーは画像内を移動します。
- 読書位置と表示設定はブラウザーに保存します。保存できない環境でも読めます。`#p=77` のようなURLは、そのページを選択して開きます。
- 出典・参照ボタンで、表示中のページのリンクを横のパネルに開けます。外部の出典は新しいタブで開きます。スマートフォンでは縦スクロールと開閉式の出典欄を使います。
- 全画面表示はブラウザーの対応が必要です。終了ボタンや Esc で戻れます。対応していない場合や開始できない場合も、そのまま通常表示で読めます。
